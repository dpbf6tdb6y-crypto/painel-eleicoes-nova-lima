Estrutura:
  site/            -> o que fica no ar (index.html, dados.js, chart.umd.min.js)
  _gerador/        -> gerar_dados.py  (recria site/dados.js a partir da planilha)
  planilhas/       -> Arquivo das eleicoes.xlsx  (fonte dos dados, do TSE)

Login do painel:  usuario jucilei / senha jucilei

DAR ACESSO A OUTRAS PESSOAS:
  Entre no painel como jucilei -> menu lateral "Acessos" (aparece so pro admin).
  Preencha Nome / Login / Senha -> Adicionar. Faca isso pra cada pessoa.
  Clique em "Copiar" e cole o texto no chat com o Claude -> ele publica.
  (Ou faca voce: "baixar como .txt", renomeie o arquivo para usuarios.js,
   salve em site/ por cima do que esta la, e git push no PC + git pull na VPS.)
  Enquanto nao publicar, o acesso novo so vale no seu navegador.


------------------------------------------------
ELEICOES 2026 - ja reservado no menu, falta so a planilha
------------------------------------------------
2026 e ano de eleicao geral (igual 2022): Presidente, Governador, Senador,
Deputado Federal e Deputado Estadual. As 6 paginas ja aparecem no menu, em
"Eleicoes 2026", marcadas "(em breve)" com um aviso de "aguardando resultado".

Quando sair o resultado oficial do TSE, adicione estas abas na MESMA
planilha (planilhas\Arquivo das eleicoes.xlsx), com as mesmas colunas que
as abas equivalentes de 2022 ja tem (nr_secao/Seçao, Nome ou Candidato,
Votos/Voto, aptos/comparecimento/abstencoes/nominais):

  "5 - Presidente 1 turno 2026"   (igual "5 - Presidente 1 turno")
  "6 - Presidente 2 turno 2026"   (igual "6 - Presidente 2 turno")
  "Governador 2026"               (igual "Governador")
  "3 Senador 2026"                (igual "3 Senador")
  "2 Deputado Federal 2026"       (igual "2 Deputado Federal")
  "1 Deputado Estadual 2026"      (igual "1 Deputado Estadual")

Dai e so rodar o gerador (passo 2 abaixo) de novo: cada pagina que achar
a aba correspondente vira pagina normal sozinha, com grafico e tudo -
nao precisa mexer no site\index.html nem me chamar pra isso.


------------------------------------------------
SECOES 2026 (local, endereco, macro e micro regiao)
------------------------------------------------
Menu lateral -> Administracao -> "Secoes 2026" (so admin).
Ali voce cria, edita e exclui secoes. A cada mudanca o texto e copiado sozinho:
cole no chat com o Claude que ele grava em site\secoes.js e publica.
(Ou "baixar secoes.js (.txt)", renomeie para secoes.js em site\, git push + git pull na VPS.)
Celulas amarelas = pendentes (A CONFIRMAR / A DEFINIR).
O gerador (gerar_dados.py) usa site\secoes.js como mapa de regioes das paginas de 2026
e grava uma copia em planilhas\Secoes 2026.xlsx para conferencia.


------------------------------------------------
ATUALIZAR OS DADOS (nova eleicao) - fluxo igual ao segov
------------------------------------------------
No SEU PC (PowerShell), na pasta desta pasta:

  1. Substitua/complete planilhas\Arquivo das eleicoes.xlsx (mesmas abas/colunas
     de sempre, mais as abas novas de 2026 quando existirem)

  2. cd _gerador ; python gerar_dados.py
     (precisa: python -m pip install pandas openpyxl)
     -> isso reescreve site\dados.js

  3. cd ..
     git add -A
     git commit -m "dados <ano>"
     git push

Na VPS:

  4. cd /srv/painel-eleicoes ; git pull

Pronto. O link https://eleicoes.gavix.tech e o login continuam iguais.
Nao precisa mexer no Caddy.


------------------------------------------------
MEXER NO PAINEL (layout, graficos, menu)
------------------------------------------------
Editar  site\index.html  direto -> git add/commit/push -> git pull na VPS.
